# 🚀 Animated Skill / Progress Bars

## 📌 Project Overview
This project is developed as part of the **Veda Technology Internship – Task: Animated Skill/Progress Bars**.

It is a responsive portfolio skills section that displays technical skills using animated progress bars. The bars smoothly fill to their respective percentages when they appear on the screen.

## 🎯 Objective
- Practice CSS animations and transitions.
- Understand JavaScript scroll detection.
- Learn how to use IntersectionObserver.
- Create a responsive skills section.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## ✨ Features
- Six animated skill progress bars.
- Percentage labels for each skill.
- Smooth filling animation.
- Scroll-based animation using IntersectionObserver.
- Responsive design for mobile and desktop.
- Attractive portfolio-style user interface.

## ⚙️ How to Run the Project

1. Clone the repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

## 💡 How It Works

1. HTML creates the skill section and progress bars.
2. CSS styles the progress bars and adds smooth transitions.
3. JavaScript uses IntersectionObserver to detect when progress bars enter the viewport.
4. The JavaScript updates the bar width using the percentage stored in the `data-width` attribute.

## 📸 Output
The website displays animated progress bars for different technical skills with percentage values.

## 🚀 Deployment
The project can be deployed using GitHub Pages.
